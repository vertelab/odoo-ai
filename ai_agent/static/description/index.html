odoo-ai: AI Agent

AI Agent orchestration — quests, sessions, tools and LLM bindings.

Odoo 1.0· AI Orchestration· by Vertel Sverige AB

Overview

The original AI Agent orchestration layer. It defines quests (structured jobs), sessions (one run of a quest), the tools an agent may call, and the LLM bindings that power them.

It is the runtime that executes a quest step by step and records every message exchanged.

Typical use: Use it as the foundation when you need scripted, multi-step AI work against Odoo records with full traceability.

Key Features

Quest sessions

ai.quest.session holds one execution with its state, while ai.quest.session.message stores the full transcript.

Tool registry with test wizard

ai.tool registers callable tools; the bundled ai.tool.test.wizard lets you invoke a tool manually and inspect the raw result.

Session objects

ai.session.object links any Odoo record to a session, so the agent can read and act on real business data.

Per-agent LLM configuration

ai.agent.llm binds a model, temperature and token limits to a specific agent.
